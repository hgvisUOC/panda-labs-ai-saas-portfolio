## ⚡ Quick Start / Local Preview

To launch the portfolio showcase locally:

```bash
# Clone the repository
git clone https://github.com/hgvisUOC/panda-labs-ai-saas-portfolio.git

# Navigate into directory
cd panda-labs-ai-saas-portfolio

# Start a local web server (Python 3)
python -m http.server 8000
```

Open `http://localhost:8000` in any modern web browser to interact with all 5 applications and view responsive previews for Desktop, Tablet (768px), and Mobile (375px).
